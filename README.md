This is a personal project to teach myself Big O Notation, Time complexity and also to familiarize myself with the basics of Git / Github.

To do this I will create an interactive time complexity game. The user will be able to input any value ranging from 0 to 50,000, which is then the size of the array that the algorithms will work with. When the algorithms are finished, they will then print what they were doing and how long it took to show what works best based on size.
